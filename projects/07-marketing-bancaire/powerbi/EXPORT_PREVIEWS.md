# Export des aperçus

Après construction dans Power BI Desktop, exporter le rapport par `Fichier → Exporter → PDF`, puis exporter une image PNG de chaque page. Nommer les fichiers `preview/07-marketing-bancaire-page-01.png`, `page-02.png` et `page-03.png`.

Noter dans ce fichier la version de Power BI Desktop utilisée et la date du dernier rafraîchissement. Les aperçus ne sont pas générés automatiquement par Python et restent une action manuelle de Samuel.
