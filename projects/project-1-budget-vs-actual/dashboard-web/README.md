# Dashboard web interactif — Civic Signal

Cette application React présente le projet Austin Budget vs Réalisé dans un navigateur. Elle reprend la structure du PDF de référence avec une palette turquoise, orange, bleu clair et gris.

## Fonctions

- Vue générale avec indicateurs Budget, Réalisé, écart et consommation.
- Filtres par année fiscale, département et catégorie.
- Boutons de navigation vers les vues Départements et Catégories.
- Tableaux cliquables et fiches de détail.
- Graphique interactif Budget contre Réalisé.

## Lancer localement

```bash
pnpm install
pnpm run dev
```

## Publication

Le site est publié dans le dépôt parent par GitHub Pages depuis la branche `gh-pages`.
