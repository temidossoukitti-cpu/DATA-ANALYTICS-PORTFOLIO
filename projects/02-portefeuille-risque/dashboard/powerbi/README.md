# Dashboard Power BI · 02-portefeuille-risque

Rapport Power BI au format **PBIP** (projet Power BI : rapport PBIR + modèle sémantique TMDL), versionnable et lisible dans Git.

## Pages

1. Vue d'ensemble
2. Performance
3. Risque
4. Corrélations
5. Tableau
6. Glossaire

## Ouvrir le rapport

1. Ouvrir `portefeuille-risque.pbip` avec **Power BI Desktop** (version récente, format PBIP activé).
2. Dans **Transformer les données → Gérer les paramètres**, régler `DossierDonnees` sur le chemin complet de ce dossier (terminé par `\`).
3. Cliquer sur **Actualiser**.

## Données utilisées

- `Projet_02_02-portefeuille-risque.xlsx`

Les caches locaux de Power BI (`.pbi/`) ne sont pas versionnés.
